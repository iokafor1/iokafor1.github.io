DAYMARK — PERSONAL FINANCE TRACKER

INSTALL ON IPHONE
1. Publish every file in this folder to a static website with HTTPS.
2. Open that HTTPS address in Safari on your iPhone.
3. Tap Share, choose “Add to Home Screen”, then tap Add.
4. Launch Daymark from its Home Screen icon. The app shell is cached for offline use after its first load.

UPDATE AN OLDER COPY
This download does not automatically replace an app already installed or files already hosted on a website. Replace the hosted files with every file in this package and reload the site in Safari. If the old appearance persists, remove the old Home Screen icon and add the updated site again.

SCREENSHOT SCANNING
Tap “Scan screenshot” and choose an image. OCR runs in your browser; the screenshot is not uploaded. The OCR engine and English recognition data load from jsDelivr, so internet is needed to scan. Recognition can misread amounts, dates or merchants: check every suggested field before saving. The category you select is remembered for the same merchant on this device.

DATA AND PRIVACY
Transactions, your chosen name, category suggestions, budgets and net-worth items are stored in this browser on this device. They are not synced or backed up online. Avoid entering private financial details on shared devices. Screenshots are processed in memory and are not stored by Daymark.

The default currency is USD. Enter a name and edit the suggested monthly budgets to make the app your own.
